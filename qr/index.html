QR Code Maker

A QR code for a link, a Wi-Fi network, a contact card and more. No tracking redirects: the code holds your content directly.

Scanning opens this page. It never expires, because the address is inside the code.
Guests point their camera at the code to join. The password is stored in the code as plain text, so print it only where you would write the password itself.

Your code

How this works

Your content is written into the code directly, in byte mode with UTF-8 text, and the smallest QR version that fits is chosen. Many free QR sites instead put their own short link in the code and redirect it, which lets them count your scans or switch the code off later. These codes have no middleman.

Formats phone cameras understand

  • Wi-Fi: WIFI:T:WPA;S:name;P:password;; with backslashes before \ ; , : and ".
  • Contact: a vCard 3.0 card.
  • Email: a mailto: link with the subject and message encoded.
  • Text message: SMSTO:number:message. Phone: tel:number.

Checked before you use it

After drawing the code, the page decodes it again with a separate decoder (jsQR) and compares the result with your content byte for byte. A code that does not decode, for example because the colours are too close, is flagged.

Printing tips

Keep the white border (the "quiet zone", four modules wide). Dark code on a light background scans most reliably. As a rule of thumb, print a code at least 2 cm wide for scanning from close up, and larger for posters seen from a distance.
